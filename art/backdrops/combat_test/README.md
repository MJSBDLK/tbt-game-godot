# Combat scene backdrop — test scene (for Lawrence)

Open **`combat_backdrop_template.aseprite`** (this folder) and paint the sky and
floor in it. Everything the runtime needs to know is drawn in as guides and
named slices; the two puppets are there for scale only.

## The canvas — 288 × 134, one art pixel = one sprite pixel

The game draws this at the puppets' 3× on the same pixel grid, nearest filter,
no parallax. Numbers come from `scripts/combat/scene/combat_scene.gd`
(`GROUND_Y`, `SKY_BOTTOM`, `LEFT_X`, `RIGHT_X` ÷ 3, plus `BACKDROP_CORE_OFFSET`)
— the brief lives in `.claude/battle-animations.md` §7.

| Guide | Where | Meaning |
|---|---|---|
| Magenta rectangle | 214 × 120 at (37, 7) | **Core — the only part every screen shows.** Nothing that must be seen goes outside it. |
| Darkened margins | columns 0–36 / 251–287, rows 0–6 / 127–133 | Bleed. Sides show on phones and ultrawide (up to 21:9); top/bottom show on the Steam Deck (8:5). Paint them, but nothing important. |
| Cyan line | row 86 | **Horizon** — the sky is rows 0–85, the floor starts on row 86. |
| Yellow line | row 91 | **Feet line** — the puppets stand on it (their bottom pixel row is 90). |
| Yellow ticks under it | x 144 ± 16 per tile | **Puppet zone.** Spacing follows the map: the two puppets stand 32 px apart per tile of distance (tiles are 32×32), centred on x 144 (each moves 16 px per tile), capped at 4 tiles — so centres range x 80 to 208. The reference puppets stand two tiles apart. |
| Red-tinted corners | 67 × 24 from (37, 7) and from (180, 7) | The HUD sits here until its restyle — keep the sky quiet under it. |

## Layers

- **`sky`** — exported as `sky.png`. Rows 0–85 (a flat palette band to start).
- **`floor`** — exported as `floor.png`. Draws OVER the sky, so hills, fences and
  props may rise above the horizon; keep the area above your horizon transparent
  where you don't want them.
- **`reference puppets — do not export`** — Max and the grunt at true scale,
  two tiles apart (Ernesto's thrust reach).
- **`GUIDES — hide before export`** — the lines above.

The project palette (`art/colors/SpacemanColorPalette_v1.41.gpl`) is attached.

## Export → the game picks it up on the next run

Two PNGs, **`sky.png`** and **`floor.png`**, in this folder. Either:

- **Script** (does the layer hiding for you). Copy
  `tools/aseprite/export_combat_backdrop.lua` into your Aseprite scripts folder
  (File ▸ Scripts ▸ Open Scripts Folder), reopen Aseprite, then with the template
  open: File ▸ Scripts ▸ export_combat_backdrop. From a terminal instead:
  `aseprite --batch art/backdrops/combat_test/combat_backdrop_template.aseprite --script tools/aseprite/export_combat_backdrop.lua`
- **By hand**: hide every layer but `sky`, File ▸ Export ▸ Export As… `sky.png`
  (full canvas, 100 %); repeat for `floor`.

`CombatScene` loads both when present and falls back to its flat bands when
they're missing, so a half-finished export never breaks a build.

The template itself is regenerated by `tools/aseprite/combat_backdrop_template.lua`
if the scene knobs ever move — don't hand-edit the guides.
