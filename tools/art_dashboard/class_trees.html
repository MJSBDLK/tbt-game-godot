Every unit has its own tree: a base class, two choices at level 21, two more under each at 41. Classes come from one shared pool, so two units can share a class, or not. Type a class name into a slot to pick it. A new name is a draft: a placeholder kept in the tree's file only, until its panel makes it a class. ⇅ flips the two branches out of a card. Edits save straight into data/classes/ in the game.
